# 🌾 KrishiMitra (कृषि मित्र)

**Smart Agricultural Procurement & Queue Management Platform**

Live Production Web App: **[https://kmitra-in.vercel.app](https://kmitra-in.vercel.app)**  
Live Backend API: **[https://krishimitra-backend-rbzu.onrender.com](https://krishimitra-backend-rbzu.onrender.com)**  
API Documentation (Swagger): **[https://krishimitra-backend-rbzu.onrender.com/api/docs](https://krishimitra-backend-rbzu.onrender.com/api/docs)**

---

## 🚀 Technology Stack

- **Frontend**: React 19, Vite, Tailwind CSS (Hosted on **Vercel**)
- **Backend**: Node.js, Express, Prisma ORM (Hosted on **Render**)
- **Database**: PostgreSQL (Hosted on **Supabase**)
